# 농업 입문자를 위한 교육 LMS 웹 서비스
본 프로젝트는 농업에 처음 입문하려는 청년들을 위한 교육용 LMS 웹 서비스 입니다.
농업 교육 콘텐츠와 사용자 권한별 기능을 제공하여,
청년들의 농업 진입 장벽을 낮추고 체계적인 학습 환경을 구축하는 것을 목표로 합니다.

프로젝트 기간 : 2025.11 - 2025.12
프로젝트 형태 : 팀 프로젝트(7명)

기술스택 
- Backend : Java, Spring Boot
- Frontend : HTML, CSS, JavaScript, Thymeleaf
- DB : MySql
- Game : Unity
- Collaboration : GitHub

역할 : 
이민우
- Java, Spring Boot 기반 백엔드 기능 구현
- 세션 기반 로그인 및 회원가입 기능 개발
- 사용자 권한에 따른 접근 제어 및 기능 분기 처리
- Thymeleaf를 활용한 권한별 화면 렌더링 로직 구현
- 마이페이지 기능 개발 ( 관리자 / 강사 / 학생 유형별 분기)


↳ 핵심 기능
회원 가입 및 로그인
- 세션 기반 인증 방식 적용
- 로그인 성공 시 사용자 권한 정보를 세션에 저장 
권한별 접근 제어
- 관리자 / 강사 / 학생 권한에 따라 접근 가능한 페이지 및 기능 분기
- 컨트롤러 및 Thymeleaf 단에서 권한 검증 처리
마이페이지
- 사용자 권한에 따라 서로 다른 마이페이지 화면 제공
- 개인 정보 조회 및 관리 기능 구현
공지사항 기능
- 관리자 권한 사용자만 공지사항 등록 및 관리 가능
- 일반 사용자는 조회만 가능하도록 권한 분리
